## 阶段顺序与责任

可靠性 → 身份/持久状态 → 聊天/任务 → 双 Worker/恢复 → 组队/记忆 → 完整浏览器联调回归 → Tauri 文档/最终验收。
每阶段给出 Pass/Return/Escalate；PM 跟进全过程，前后端专业分工，QA 独立验证，主代理集成验收，DevOps 负责环境和恢复，文档随真实状态更新。

先完成已授权且无环境依赖的工作；关键真实链路未测不得判定目标完成。Mock只证明注入场景，不替代浏览器、Docker或真实模型。Docker/WSL系统变更若需要管理员或重启则单独请求最小授权；模型仅用现有授权配置和费用边界。

## 数据与交付边界

- SQLite 默认独立用户数据目录，支持 `CORPPILOT_WORKBENCH_HOME`；测试仅使用临时数据库。
- 旧 JSON 迁移前备份并校验数量/引用，切换后不长期双写；不得删除真实历史/记忆来通过测试。
- Worker 只能得到本次授权上下文、工具和挂载；Owner管理接口不能直接暴露给 Worker。
- 本轮不要求 Tauri 安装包、第二种 CLI、多机集群或自动训练模型；本轮必须真实完成至少一种 CLI 与双 Docker Worker。
- 分功能证据见 [交付台账](feature-delivery-log.md)，不将本地通过标为远端交付。

## F35 Owner 确认的项目协作计划（后端与 HTTP 已验证）

从私聊或群聊中选择一条本会话 Owner 目标消息，由 Owner 明确填写可共享摘要 `shared_brief`、项目标题、协调人及 1–16 项任务。每项任务包含负责人、目标、范围、验收标准和本计划内的前置任务；成员取协调人与任务负责人，协调人须属于源会话，所有选定身份须启用。依赖必须无环，不能引用计划外任务。

Owner 明确提交后，在一个事务中创建新项目会话、成员、共享摘要消息、v1 任务及依赖，并保存不可变创建回执；任一校验或写入失败均不保留半成品。相同源会话与请求键只接受同一计划，重试回读原创建结果。创建、重放和历史查询的回执均含 `approved_plan` 原计划，后续任务修改不会替换 Owner 当时确认的内容。新项目只接收明确共享的摘要和任务字段，不自动复制源私聊/群聊历史或个人记忆；源目标仅作为来源引用保留。

此增量不调用模型、不自动回复或启动执行。成员选择和任务拆分由 Owner 明确确认，尚不代表按技能/资源/预算智能组队；真实执行继续使用既有任务执行与评审门。验收覆盖原子回滚、DAG/成员校验、同键并发重试、历史不复制和零执行副作用。后端及 HTTP 定向 30 项通过、Tech Lead 审查 Pass；主代理全量 421 项及 8 子用例通过（65.34s）。F36 已补齐浏览器入口，F37/F38 已提供提案后端与浏览器导入再次确认；自动组队和真实执行闭环仍未完成，整体目标保持未完成。

## F36 浏览器项目组建与恢复（已验证）

Owner 消息下可打开“组建协作项目”，主动填写初始为空的共享摘要、项目名、协调人及任务计划；提交前展示全部任务、依赖和成员并要求明确确认。循环依赖阻止提交，来源和身份权限由后端复查；成功后显示当时批准的原计划并打开新项目。该入口由 Owner 决定拆分和成员，技能标签只作参考，不自动调用模型、组队或执行。

已发送原计划在当前标签页持久保存，切换会话或刷新后可从全局“协作计划与恢复”回到原来源核对。首次明确拒绝可保留全文重新编辑；核对原请求前清除早先拒绝标记，若后续响应未知则只沿原键恢复。读取失败不显示为空，源会话归档后仍能核对已提交原计划，已确认回执不因后续 GET 失败丢失。

主代理真实浏览器与独立数据回读验证普通创建、循环阻止、成员停用拒绝及重编辑、提交后丢失响应、GET 503、跨会话刷新恢复和同键只创建一次。两个样本项目共三任务，成员/依赖正确、无私聊历史复制，无 CLI/模型调用。最终 42 modules 构建通过（index-DS6DJ8Di.js），沿用 F35 后端全量 421 项及 8 子用例；本增量不重复宣称后端全量测试，也不代表模型提案、技能路由或完整目标完成。

## F37 白名单内的模型协作提案（后端与 API 已验证）
