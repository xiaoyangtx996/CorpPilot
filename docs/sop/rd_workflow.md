# 研发中心内部工作流 SOP

## 适用范围

研发中心收到 PMO 派发的技术研发任务后的完整执行流程。

## 角色分工

| 角色 | 职责 |
|------|------|
| 研发总监 | 接收任务、评估复杂度、协调资源 |
| 架构师 | 技术方案设计、代码评审 |
| 后端开发工程师 | 后端编码实现 |
| 前端开发工程师 | 前端编码实现 |
| 测试工程师 | 测试用例和执行 |
| 运维工程师 | 部署上线 |

## 流程步骤

### 1. 任务接收（研发总监）

- 接收 PMO 派发指令
- 评估技术复杂度
- 判断当前人力是否充足
- 人力不足时向 PMO 发起 resource_request

### 2. 技术方案设计（架构师）

- 与产品经理做技术可行性评审
- 确定技术选型
- 设计系统架构
- 输出架构决策记录（ADR）
- 将任务拆分为后端/前端/测试子任务

### 3. 编码实现（后端/前端工程师）

- 按架构设计实现功能
- 编写单元测试
- 提交代码评审

### 4. 代码评审（架构师）

- 审查代码质量和架构一致性
- 通过 → 进入测试
- 不通过 → 退回修改

### 5. 测试验证（测试工程师）

- 执行功能测试、集成测试
- 记录和跟踪缺陷
- 全部通过 → 进入部署
- 有缺陷 → 退回开发修复

### 6. 部署上线（运维工程师）

- 部署到测试环境验证
- 灰度发布到生产环境
- 监控服务稳定性

### 7. 交付确认（研发总监）

- 确认交付物完整
- 汇报 PMO 项目完成
- 动态 Agent 不再需要时通知 HR 回收
