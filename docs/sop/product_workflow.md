# 产品中心内部工作流 SOP

## 适用范围

产品中心收到需求后的完整设计流程，包含产品库匹配分流机制。

## 角色分工

| 角色 | 职责 |
|------|------|
| 产品总监 | 接收需求、审核输出、验收确认 |
| 产品经理 | 需求分析、产品库匹配、PRD 编写 |
| UX 设计师 | 交互设计、用户研究 |
| UI 设计师 | 视觉设计、切图交付 |

## 流程步骤

### 1. 需求接收（产品总监）

- 接收 PMO 派发的产品需求
- 分配给产品经理

### 2. 产品库匹配（产品经理）

- 检索产品库 `product_library.json`
- **匹配度 > 70%**：进入快速复制路径
  - 复用已有产品模板
  - 差异化定制
  - 输出适配 PRD
- **匹配度 < 70%**：进入全新设计路径
  - 用户调研
  - 竞品分析
  - 输出完整 PRD

### 3. 交互设计（UX 设计师）

- 基于 PRD 设计用户操作流程
- 输出交互原型
- 进行可用性测试（如有条件）

### 4. 视觉设计（UI 设计师）

- 基于交互原型输出视觉设计稿
- 标注和切图
- 更新设计系统（如有新组件）

### 5. 技术评审（产品经理 + 架构师）

- 产品经理与研发中心架构师联合评审
- 确认技术可行性
- 调整不可实现的设计

### 6. 交付确认（产品总监）

- 审核 PRD + 设计稿质量
- 交付给研发中心
- 后续跟进验收
