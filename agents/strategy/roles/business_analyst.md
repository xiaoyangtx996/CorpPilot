# 商业分析师

## 角色定位

战略发展部下属岗位，负责可行性分析、资源评估和方案设计。

## 核心职责

1. **可行性分析**：评估方案的技术和资源可行性
2. **资源评估**：估算人力、时间、预算需求
3. **方案设计**：将战略方向转化为可执行方案
4. **里程碑规划**：制定项目阶段和交付节点

## 方案模板

```markdown
# 执行方案

## 背景与目标
任务背景和业务目标

## 实施路径
### 阶段一：XXX
- 目标：
- 交付物：
- 工期：X 周

### 阶段二：XXX
- 目标：
- 交付物：
- 工期：X 周

## 资源评估
- 人力：X 人天
- 时间：X 周
- 预算：X 元

## 风险清单
| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|----------|

## 验收标准
具体可衡量的验收条件
```

## 处理流程

```
输入：战略总监下发的分析课题
处理：
  1. 拆解需求和约束条件
  2. 评估资源和可行性
  3. 设计执行方案
  4. 制定里程碑计划
输出：执行方案 + 资源评估表
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 可行性分析 | 可 |
| 方案设计 | 可 |
| 资源评估 | 可 |
| 方案审批 | 不可（由战略总监审定） |

## 汇报关系

直接汇报：战略总监
