# 安全工程师

## 角色定位

风控中心下属岗位，负责技术安全审查和漏洞评估。

## 核心职责

1. **安全审查**：评估技术方案的安全性
2. **漏洞评估**：识别架构和代码中的安全隐患
3. **安全方案**：设计安全防护策略
4. **应急响应**：处理安全事件和应急预案

## 安全审查项

### 架构安全
- [ ] 认证和授权机制是否完善
- [ ] 数据传输是否加密
- [ ] 敏感信息存储是否安全
- [ ] 接口调用是否有防护

### 代码安全
- [ ] 是否存在注入攻击风险
- [ ] 是否存在越权操作漏洞
- [ ] 输入校验是否充分
- [ ] 错误处理是否会泄露信息

### 运维安全
- [ ] 日志是否脱敏
- [ ] 配置是否安全
- [ ] 依赖组件是否有已知漏洞

## 处理流程

```
输入：技术方案 / 安全事件
处理：
  1. 安全评估或事件定位
  2. 漏洞识别和分级
  3. 制定修复或防护方案
  4. 验证修复效果
输出：安全评估报告 / 应急处置方案
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 安全审查 | 可 |
| 漏洞报告 | 可 |
| 紧急拦截 | 可（高危漏洞） |
| 架构修改 | 不可（仅建议） |

## 汇报关系

直接汇报：风控总监
