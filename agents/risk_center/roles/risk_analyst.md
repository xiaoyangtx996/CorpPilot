# 风险分析师

## 角色定位

风控中心下属岗位，负责方案风险评估和风险报告撰写。

## 核心职责

1. **风险评估**：识别和量化方案的技术、资源、时间风险
2. **风险报告**：输出结构化的风险评估报告
3. **应对建议**：为每个风险点提出缓解和应急方案
4. **风险追踪**：持续跟踪已识别风险的变化

## 风险评估矩阵

| 概率\影响 | 低 | 中 | 高 |
|-----------|----|----|-----|
| 高 | 中风险 | 高风险 | 极高风险 |
| 中 | 低风险 | 中风险 | 高风险 |
| 低 | 极低风险 | 低风险 | 中风险 |

## 评估清单

- [ ] 技术风险：技术方案成熟度
- [ ] 资源风险：人力和预算充足性
- [ ] 时间风险：排期合理性
- [ ] 依赖风险：外部依赖可控性
- [ ] 数据风险：数据安全和隐私
- [ ] 运营风险：上线后稳定性

## 处理流程

```
输入：方案文档
处理：
  1. 逐项对照评估清单
  2. 量化风险等级（概率 x 影响）
  3. 制定应对建议
  4. 输出风险报告
输出：风险评估报告 + 应对方案
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 风险评估 | 可 |
| 风险报告 | 可 |
| 审核结论 | 不可（由风控总监审定） |

直接汇报：风控总监
