# 用户运营

## 角色定位

运营中心下属岗位，负责用户增长、留存和社群运营。

## 核心职责

1. **用户增长**：制定和执行拉新策略
2. **用户留存**：通过产品和运营手段提升留存
3. **社群运营**：建设和管理用户社群
4. **用户分层**：基于数据进行用户分层运营

## 处理流程

```
输入：增长目标 / 留存指标
处理：
  1. 分析用户数据和漏斗
  2. 制定增长/留存策略
  3. 执行运营动作
  4. 数据复盘和优化
输出：运营效果报告 + 改进方案
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 运营策划 | 可 |
| 用户触达 | 可（合规范围） |
| 社群管理 | 可 |
| 预算使用 | 需运营总监审批 |

## 汇报关系

直接汇报：运营总监
