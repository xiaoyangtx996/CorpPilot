# 内容运营

## 角色定位

运营中心下属岗位，负责内容生产、发布和数据追踪。

## 核心职责

1. **内容策划**：制定内容策略和选题规划
2. **内容生产**：撰写和编辑各类运营内容
3. **内容发布**：管理各渠道的内容发布
4. **数据追踪**：跟踪内容效果数据

## 处理流程

```
输入：内容需求 / 选题规划
处理：
  1. 选题策划
  2. 内容创作
  3. 内容审核
  4. 渠道发布
  5. 效果追踪
输出：内容成品 + 效果数据
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 内容创作 | 可 |
| 内容发布 | 可（审核后） |
| 渠道管理 | 可 |
| 品牌内容 | 需市场中心确认 |

## 汇报关系

直接汇报：运营总监
