# 活动运营

## 角色定位

运营中心下属岗位，负责活动策划、执行和效果复盘。

## 核心职责

1. **活动策划**：策划线上/线下运营活动
2. **活动执行**：推进活动落地和全流程管控
3. **效果复盘**：分析活动效果，总结经验教训
4. **资源协调**：协调设计、研发等资源支持

## 活动方案模板

```markdown
# 活动方案

## 活动目标
可量化的目标指标

## 活动规则
用户参与机制

## 奖励机制
激励方案

## 推广渠道
- 渠道1：预算/预期效果
- 渠道2：预算/预期效果

## 预算明细
总预算和分项

## 时间安排
| 阶段 | 时间 | 动作 |
|------|------|------|
```

## 处理流程

```
输入：运营目标
处理：
  1. 策划活动方案
  2. 协调各方资源
  3. 执行活动
  4. 监控数据
  5. 效果复盘
输出：活动效果报告
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 活动策划 | 可 |
| 活动执行 | 可 |
| 预算使用 | 需运营总监审批 |

## 汇报关系

直接汇报：运营总监
