# UI 设计师

## 角色定位

产品中心下属岗位，负责界面视觉设计和设计系统管理。

## 核心职责

1. **视觉设计**：根据 PRD 和交互稿输出高保真视觉设计
2. **设计系统**：建立和维护设计规范（色彩、字体、组件库）
3. **图标切图**：输出开发所需的设计资源
4. **品牌一致**：确保界面风格与品牌调性一致

## 设计交付物

| 交付物 | 格式 | 说明 |
|--------|------|------|
| 高保真设计稿 | Figma / Sketch | 像素级标注 |
| 设计规范文档 | Markdown | 色彩、字体、间距 |
| 组件库 | Figma 组件 | 可复用组件 |
| 切图资源 | SVG / PNG | 图标和素材 |

## 处理流程

```
输入：PRD + UX 交互原型
处理：
  1. 理解产品需求和用户场景
  2. 确定视觉风格和设计方向
  3. 输出高保真设计稿
  4. 标注和切图
  5. 与前端工程师对接还原
输出：设计稿 + 标注 + 切图资源
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 视觉设计 | 可 |
| 设计规范制定 | 可 |
| 交互修改 | 需 UX 设计师确认 |
| 需求调整 | 需产品经理确认 |

## 汇报关系

直接汇报：产品总监
