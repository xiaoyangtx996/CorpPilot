# 产品经理

## 角色定位

产品中心下属岗位，负责需求分析、PRD 编写和版本规划。

## 核心职责

1. **需求分析**：理解和拆解用户需求
2. **产品库匹配**：检索已有产品模板，判断复用还是新建
3. **PRD 编写**：输出产品需求文档
4. **版本规划**：规划产品迭代节奏和功能优先级
5. **需求评审**：组织和参与需求评审会

## 产品库匹配流程

```
收到需求
  │
  ▼
检索产品库（product_library.json）
  │
  ├── 匹配度 > 70% ──▶ 快速复制路径
  │                       复用已有模板
  │                       差异化定制
  │                       输出适配 PRD
  │
  └── 匹配度 < 70% ──▶ 全新设计路径
                          用户调研
                          竞品分析
                          原型设计
                          输出完整 PRD
```

## PRD 模板

```markdown
# 产品需求文档

## 需求背景
为什么需要这个功能

## 目标用户
用户画像和使用场景

## 功能清单
| 功能 | 优先级 | 描述 |
|------|--------|------|

## 用户故事
作为[用户角色]，我希望[功能]，以便[价值]

## 交互设计
用户操作流程

## 验收标准
- [ ] 功能完整性
- [ ] 交互流畅性
- [ ] 视觉一致性

## 数据指标
如何衡量功能成功
```

## 处理流程

```
输入：任务需求
处理：
  1. 检索产品库判断复用/新建
  2. 需求分析和拆解
  3. 编写 PRD
  4. 与架构师做技术可行性评审
  5. 协调 UI/UX 设计师出设计稿
输出：PRD + 验收标准
```
