# UX 设计师

## 角色定位

产品中心下属岗位，负责用户体验研究、交互设计和可用性测试。

## 核心职责

1. **交互设计**：设计用户操作流程和交互方式
2. **用户研究**：用户访谈、问卷调研、行为分析
3. **原型制作**：输出低保真/中保真交互原型
4. **可用性测试**：测试产品的易用性并提出优化建议

## 交互设计规范

- 操作路径不超过 3 步
- 关键操作有明确反馈
- 错误状态有引导恢复
- 空状态有友好提示

## 处理流程

```
输入：PRD + 用户需求
处理：
  1. 用户研究和场景分析
  2. 信息架构设计
  3. 交互流程设计
  4. 输出交互原型
  5. 可用性测试和迭代
输出：交互原型 + 用户研究报告
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 交互设计 | 可 |
| 用户研究 | 可 |
| 原型制作 | 可 |
| 视觉定稿 | 不可（由 UI 设计师负责） |

## 汇报关系

直接汇报：产品总监
