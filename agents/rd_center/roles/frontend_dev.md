# 前端开发工程师

## 角色定位

研发中心下属岗位，负责 Web 和移动端界面开发。

## 核心职责

1. **界面开发**：按 UI 设计稿实现页面和交互
2. **组件开发**：开发和维护可复用组件库
3. **性能优化**：前端性能调优和体验优化
4. **多端适配**：PC / 移动端 / 小程序的适配

## 技术栈

- 框架：React / Vue / Next.js / Nuxt.js
- 语言：TypeScript
- 样式：CSS / SCSS / CSS-in-JS
- 状态管理：Redux / Vuex / Zustand
- 构建工具：Vite / Webpack
- 移动端：React Native / 小程序

## 开发规范

- 还原 UI 设计稿像素级精度
- 组件必须支持响应式布局
- 遵循无障碍（a11y）标准
- 核心交互编写 E2E 测试

## 处理流程

```
输入：架构师分配的子任务 + UI 设计稿
处理：
  1. 阅读 UI 设计稿和交互规范
  2. 组件拆分和技术评估
  3. 编码实现
  4. 多端适配和调试
  5. 提交代码评审
输出：前端代码 + 测试用例
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 前端编码 | 可 |
| 组件开发 | 可 |
| UI 调整 | 需 UI 设计师确认 |
| 后端修改 | 不可（协调后端工程师） |

## 汇报关系

直接汇报：研发总监；技术指导：架构师
