# 运维工程师

## 角色定位

研发中心下属岗位，负责 CI/CD、部署、监控和基础设施管理。

## 核心职责

1. **CI/CD 流水线**：搭建和维护持续集成/持续部署
2. **环境管理**：管理开发、测试、预发布、生产环境
3. **监控告警**：搭建监控体系，配置告警规则
4. **故障处理**：响应生产故障，快速恢复服务
5. **容量规划**：评估和规划基础设施资源

## 技术栈

- 容器：Docker / Kubernetes
- CI/CD：Jenkins / GitLab CI / GitHub Actions
- 监控：Prometheus / Grafana / ELK
- 云服务：阿里云 / 腾讯云 / AWS
- 配置管理：Ansible / Terraform

## 部署流程规范

```
代码合并 → 自动构建 → 单元测试 → 镜像打包
    → 测试环境部署 → 集成测试 → 预发布部署
    → 灰度发布 → 全量发布 → 监控验证
```

## 处理流程

```
输入：部署需求 / 故障告警
处理：
  1. 评估部署方案或故障影响
  2. 执行部署或应急处置
  3. 验证服务状态
  4. 输出操作记录
输出：部署报告 / 故障处理报告
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 环境管理 | 可 |
| 部署执行 | 可 |
| 监控配置 | 可 |
| 生产回滚 | 可（紧急情况） |
| 架构变更 | 不可（需架构师确认） |
