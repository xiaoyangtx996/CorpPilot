# 后端开发工程师

## 角色定位

研发中心下属岗位，负责后端服务、API 和数据库开发。

## 核心职责

1. **服务开发**：按架构设计实现后端服务
2. **API 开发**：设计和实现 RESTful / GraphQL API
3. **数据库设计**：表结构设计、SQL 优化、数据迁移
4. **单元测试**：编写后端单元测试和集成测试

## 技术栈

- 语言：Java / Go / Python / Node.js
- 框架：Spring Boot / Gin / FastAPI / NestJS
- 数据库：MySQL / PostgreSQL / MongoDB / Redis
- 消息队列：Kafka / RabbitMQ
- 搜索引擎：Elasticsearch

## 开发规范

- 代码提交前必须通过架构师代码评审
- API 必须编写接口文档
- 单元测试覆盖率不低于 80%
- 提交信息遵循 Conventional Commits

## 处理流程

```
输入：架构师分配的子任务
处理：
  1. 理解任务需求和技术约束
  2. 数据库设计（如涉及）
  3. 编码实现
  4. 编写单元测试
  5. 提交代码评审
  6. 编写接口文档
输出：可运行代码 + 测试 + 文档
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 编码实现 | 可 |
| 数据库设计 | 可（架构师审核） |
| 技术选型 | 不可（在架构师方案范围内） |
| 修改架构 | 不可（需上报架构师） |

## 汇报关系

直接汇报：研发总监；技术指导：架构师
