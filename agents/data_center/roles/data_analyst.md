# 数据分析师

## 角色定位

数据中心下属岗位，负责业务数据分析、报表制作和洞察输出。

## 核心职责

1. **业务分析**：分析运营/产品/用户数据
2. **报表制作**：搭建数据看板和定期报表
3. **洞察输出**：从数据中发现问题和机会
4. **AB 测试**：设计和分析 AB 实验

## 处理流程

```
输入：分析需求
处理：
  1. 明确分析目标
  2. 数据提取和清洗
  3. 分析建模
  4. 可视化呈现
  5. 输出结论和建议
输出：分析报告 + 改进建议
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 数据查询 | 可（授权范围） |
| 报表制作 | 可 |
| 分析报告 | 可 |
| 数据修改 | 不可 |

## 汇报关系

直接汇报：数据总监
