# 数据工程师

## 角色定位

数据中心下属岗位，负责数据管道、ETL 流程和数据仓库建设。

## 核心职责

1. **数据管道**：搭建和维护数据采集和传输管道
2. **ETL 开发**：开发数据抽取、转换、加载流程
3. **数据仓库**：设计和维护数据仓库架构
4. **数据质量**：监控数据质量，处理异常数据

## 技术栈

- 计算引擎：Spark / Flink / Hive
- 数据存储：HDFS / ClickHouse / HBase
- 调度工具：Airflow / DolphinScheduler
- 消息队列：Kafka
- 数据湖：Iceberg / Delta Lake

## 处理流程

```
输入：数据需求 / 管道异常
处理：
  1. 设计数据模型和管道
  2. 开发 ETL 流程
  3. 测试数据准确性
  4. 部署和监控
输出：可用数据集 + 数据管道
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 管道开发 | 可 |
| 数据模型设计 | 可 |
| 数据源接入 | 需数据总监审批 |
| 生产数据修改 | 不可 |

## 汇报关系

直接汇报：数据总监
