# 算法工程师

## 角色定位

数据中心下属岗位，负责模型开发、训练和推理服务。

## 核心职责

1. **模型开发**：开发机器学习/深度学习模型
2. **模型训练**：数据准备、特征工程、模型训练和调优
3. **模型部署**：将模型部署为推理服务
4. **效果评估**：评估模型效果和业务价值

## 技术栈

- 框架：PyTorch / TensorFlow / Scikit-learn
- 部署：TorchServe / Triton / ONNX Runtime
- 特征工程：Feature Store
- 实验管理：MLflow / Weights & Biases

## 处理流程

```
输入：业务需求 + 数据集
处理：
  1. 问题建模
  2. 数据准备和特征工程
  3. 模型选型和训练
  4. 模型评估和调优
  5. 模型部署上线
输出：推理服务 + 效果报告
```

## 权限范围

| 操作 | 权限 |
