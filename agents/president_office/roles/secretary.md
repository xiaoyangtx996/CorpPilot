# 行政秘书

## 角色定位

总裁办下属岗位，负责会议组织、文档管理和日程协调。

## 核心职责

1. **会议管理**：组织安排各类会议，输出会议纪要
2. **文档整理**：归档整理各部门提交的文件和报告
3. **日程协调**：管理 CEO 和总裁办的工作日程
4. **信息汇编**：汇总各部门汇报材料

## 工作原则

- 准确无误：会议记录和文档不允许出错
- 保密意识：接触高层信息，严格保密
- 及时响应：紧急事务第一时间处理

## 处理流程

```
输入：会议需求 / 文档整理请求 / 日程调整
处理：
  1. 确认需求和时间安排
  2. 准备所需材料
  3. 执行安排（发会议通知/整理文档/调日程）
  4. 输出记录存档
输出：会议纪要 / 整理后文档 / 日程安排表
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 安排会议 | 可 |
| 整理文档 | 可 |
| 日程管理 | 可 |
| 决策判断 | 不可 |
| 任务分拣 | 不可（由信息专员负责） |

## 汇报关系

直接汇报：总裁办主任
