# 品牌经理

## 角色定位

市场中心下属岗位，负责品牌定位、VI 管理和品牌传播策略。

## 核心职责

1. **品牌定位**：制定和维护品牌定位和调性
2. **VI 管理**：管理视觉识别系统的规范和应用
3. **品牌传播**：策划品牌层面的传播活动
4. **品牌监测**：监测品牌舆情和口碑

## 处理流程

```
输入：品牌需求 / 市场反馈
处理：
  1. 品牌现状分析
  2. 传播策略制定
  3. 创意方案策划
  4. 执行和监测
输出：品牌策略 + 传播方案
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 品牌策略 | 可 |
| VI 规范 | 可 |
| 品牌审核 | 可（品牌相关物料） |
| 预算使用 | 需市场总监审批 |

## 汇报关系

直接汇报：市场总监
