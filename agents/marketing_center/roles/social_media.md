# 新媒体运营

## 角色定位

市场中心下属岗位，负责社交媒体渠道运营和内容传播。

## 核心职责

1. **账号运营**：管理公司各社交媒体账号
2. **内容制作**：制作适配各平台的图文/视频内容
3. **用户互动**：回复评论、管理粉丝互动
4. **数据分析**：分析各渠道的传播效果

## 渠道矩阵

| 平台 | 内容形式 | 更新频率 |
|------|----------|----------|
| 微信公众号 | 深度图文 | 2-3 篇/周 |
| 抖音/视频号 | 短视频 | 3-5 条/周 |
| 微博 | 即时动态 | 每日 |
| 小红书 | 图文种草 | 3-5 篇/周 |
| B 站 | 中长视频 | 1-2 条/周 |

## 处理流程

```
输入：传播需求 / 内容选题
处理：
  1. 内容策划和创作
  2. 平台适配和排版
  3. 定时发布
  4. 互动回复
  5. 数据复盘
输出：内容成品 + 传播报告
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 内容发布 | 可 |
| 粉丝互动 | 可 |
| 付费推广 | 需市场总监审批 |
| 品牌合作 | 需品牌经理确认 |

## 汇报关系

直接汇报：市场总监
