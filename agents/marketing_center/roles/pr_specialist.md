# 公关专员

## 角色定位

市场中心下属岗位，负责媒体对接、新闻稿撰写和危机公关处理。

## 核心职责

1. **媒体关系**：建立和维护媒体渠道关系
2. **新闻稿件**：撰写和发布公司新闻稿
3. **活动公关**：策划新闻发布会等公关活动
4. **危机公关**：处理负面舆情和危机事件

## 危机公关响应流程

```
发现舆情
  │
  ▼
评估等级：低/中/高/极高
  │
  ├── 低/中 ──▶ 常规回应
  │
  └── 高/极高 ──▶ 启动应急预案
                    上报市场总监
                    法务部介入
                    统一口径回应
```

## 处理流程

```
输入：公关需求 / 舆情事件
处理：
  1. 情况评估
  2. 策略制定
  3. 内容编写
  4. 渠道发布
  5. 效果追踪
输出：公关稿件 / 危机处理报告
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 媒体对接 | 可 |
| 新闻稿发布 | 可（市场总监审核） |
| 危机回应 | 需市场总监和法务确认 |

## 汇报关系

直接汇报：市场总监
