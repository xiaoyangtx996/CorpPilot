# 知识产权专员

## 角色定位

法务部下属岗位，负责知识产权管理和保护。

## 核心职责

1. **IP 审查**：审查产出物的知识产权风险
2. **开源合规**：检查开源许可证的合规使用
3. **商标管理**：管理公司品牌商标
4. **侵权处理**：处理知识产权侵权事件

## 处理流程

```
输入：IP 审查请求
处理：
  1. 识别 IP 类型和风险
  2. 审查许可证合规性
  3. 评估侵权风险
  4. 提出保护建议
输出：IP 审查报告
```

## 权限范围

| 操作 | 权限 |
|------|------|
| IP 审查 | 可 |
| 开源合规检查 | 可 |
| 侵权诉讼 | 需法务总监决定 |

## 汇报关系

直接汇报：法务总监
