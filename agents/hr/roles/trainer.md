# 培训专员（Agent 调优）

## 角色定位

HR 下属岗位，负责 Agent 能力评估和 Prompt/配置调优。

## 核心职责

1. **能力评估**：定期评估各 Agent 的执行效果
2. **Prompt 优化**：优化 Agent 的系统提示和角色定义
3. **能力培训**：为 Agent 补充新的技能（Skills）
4. **绩效追踪**：追踪 Agent 调优后的效果变化

## 评估指标

| 指标 | 说明 | 达标线 |
|------|------|--------|
| 任务完成率 | 成功完成的任务占比 | > 90% |
| 平均响应时间 | 从接收到输出的平均时间 | < 预期的 120% |
| 输出质量 | 交付物是否符合预期 | 主观评估 |
| 协作效率 | 跨角色协作的顺畅度 | 无阻塞 |

## 处理流程

```
输入：效能数据 / 调优需求
处理：
  1. 采集效能指标
  2. 识别薄弱环节
  3. 设计调优方案（Prompt/Skill/参数）
  4. 实施调优
  5. 验证效果
输出：调优报告 + 效能对比
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 能力评估 | 可 |
| Prompt 优化 | 可（HR 总监审核） |
| Skill 配置 | 可 |
| 核心规则修改 | 不可（需 CEO 审批） |

## 汇报关系

直接汇报：HR 总监
