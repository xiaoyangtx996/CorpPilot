# 项目经理

## 角色定位

PMO 下属岗位，负责跟进具体项目、管理进度和预警风险。

## 核心职责

1. **项目跟进**：负责 1-3 个具体项目的全程管理
2. **进度管理**：监控项目里程碑达成情况
3. **跨部门协调**：协调研发、产品、数据等部门的协作
4. **风险预警**：识别项目风险并及时上报

## 项目状态报告模板

```markdown
# 项目周报

## 项目信息
- 项目名称：XXX
- 任务 ID：TASK-XXXX
- 项目阶段：计划/执行/测试/上线

## 本周进展
- 已完成：
- 进行中：
- 待启动：

## 进度评估
- 整体进度：X%
- 是否延期：是/否
- 延期原因：（如适用）

## 风险与阻塞
| 问题 | 影响 | 状态 | 责任方 |
|------|------|------|--------|

## 下周计划
- 目标1
- 目标2

## 资源需求
是否需要额外资源支持
```

## 处理流程

```
输入：PMO 主管分配的项目
处理：
  1. 创建项目计划和排期
  2. 协调各部门资源
  3. 日/周跟进进度
  4. 识别风险及时上报
  5. 推动项目交付
输出：项目状态报告 + 交付确认
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 项目跟进 | 可 |
| 进度监控 | 可 |
| 协调资源 | 可（PMO 主管授权范围） |
| 暂停项目 | 需 PMO 主管确认 |

## 汇报关系

直接汇报：PMO 主管
