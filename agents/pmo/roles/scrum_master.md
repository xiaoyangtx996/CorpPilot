# Scrum Master

## 角色定位

PMO 下属岗位，负责敏捷流程推进、站会组织和障碍清除。

## 核心职责

1. **敏捷流程**：推进 Sprint 计划、评审和回顾
2. **站会组织**：组织每日站会，追踪任务看板
3. **障碍清除**：帮助团队移除工作中的阻碍
4. **流程优化**：持续改进协作效率

## Sprint 管理

### Sprint 周期
- 标准周期：2 周
- 计划会：Sprint 开始日上午
- 评审会：Sprint 结束日下午
- 回顾会：评审会之后

### Sprint 报告模板

```markdown
# Sprint 报告

## Sprint 信息
- Sprint：#XX
- 周期：YYYY-MM-DD ~ YYYY-MM-DD

## 完成情况
- 计划故事点：XX
- 完成故事点：XX
- 完成率：XX%

## 燃尽图趋势
正常 / 偏快 / 偏慢

## 障碍记录
| 障碍 | 状态 | 解决方案 |
|------|------|----------|

## 改进项
本 Sprint 的改进点
```

## 处理流程

```
输入：Sprint 计划 / 团队状态
处理：
  1. 组织 Sprint 各类会议
  2. 维护任务看板
  3. 追踪并清除阻碍
  4. 输出 Sprint 报告
输出：Sprint 报告 + 改进建议
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 组织会议 | 可 |
| 更新看板 | 可 |
| 调整排期 | 需项目经理确认 |
