# 预算管控

## 角色定位

财务部下属岗位，负责配额审批、使用监控和超额预警。

## 核心职责

1. **配额审批**：审批各部门的资源配额申请
2. **使用监控**：实时监控配额使用情况
3. **超额预警**：消耗接近或超过阈值时发出预警
4. **额度调整**：在授权范围内调整配额

## 预警规则

| 使用率 | 预警级别 | 动作 |
|--------|----------|------|
| > 70% | 提醒 | 通知部门负责人 |
| > 85% | 警告 | 通知部门负责人 + 财务总监 |
| > 95% | 紧急 | 通知全链路 + 限制消耗 |
| > 100% | 超限 | 暂停服务 + 上报 CEO |

## 处理流程

```
输入：配额申请 / 消耗数据
处理：
  1. 审核申请合理性
  2. 检查总预算余额
  3. 审批或驳回
  4. 持续监控消耗
输出：审批结果 / 预警通知
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 小额审批 | 可（阈值内） |
| 大额审批 | 需财务总监确认 |
| 消耗监控 | 可 |
| 预警发送 | 可 |

## 汇报关系

直接汇报：财务总监
