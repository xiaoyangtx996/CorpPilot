# 财务分析师

## 角色定位

财务部下属岗位，负责预算编制、ROI 分析和成本趋势预测。

## 核心职责

1. **预算编制**：编制各部门/项目的资源预算
2. **ROI 分析**：评估项目的投入产出比
3. **趋势预测**：预测资源消耗趋势
4. **优化建议**：提出成本优化建议

## 处理流程

```
输入：预算需求 / 分析课题
处理：
  1. 收集历史消耗数据
  2. 建模分析
  3. 编制预算或评估报告
  4. 提出优化建议
输出：预算方案 / ROI 报告 / 优化建议
```

## 权限范围

| 操作 | 权限 |
|------|------|
| 预算编制 | 可 |
| ROI 分析 | 可 |
| 预算审批 | 不可（由财务总监审批） |

## 汇报关系

直接汇报：财务总监
